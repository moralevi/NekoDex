# Data sources

Every external source NekoDex uses, with how it is used, its terms and the attribution required. Update this file whenever a source is added, removed or used differently.

## Game data (Lumina)

- **What:** Excel sheets read from the player's own game installation through Dalamud's `IDataManager` (Mount, Companion, Orchestrion/OrchestrionUiparam, Emote, BuddyEquip, Ornament, GlassesStyle and TripleTriadCard sheets: names, icons, order). The generator in `tools/DataGen` reads the same sheets from the local install to validate the dataset and record the game version.
- **Use:** entry lists and icons. Nothing is redistributed; the plugin reads whatever client the user has installed.
- **Terms:** FINAL FANTASY XIV © SQUARE ENIX CO., LTD. Names and icons are displayed in the user's own client only.

## Character state (FFXIVClientStructs)

- **What:** `PlayerState.IsMountUnlocked`, `PlayerState.IsOrchestrionRollUnlocked`, `UIState.IsCompanionUnlocked`, `UIState.IsEmoteUnlocked`, `UIState.IsTripleTriadCardUnlocked`, `CompanionInfo.IsBuddyEquipUnlocked`, `PlayerState.IsOrnamentUnlocked` and `PlayerState.IsGlassesStyleUnlocked`, plus roulette, tribal and Wondrous Tails state for the checklist, all read from the running game's memory.
- **Use:** owned / missing status. Read-only; nothing is written.

## FFXIV Collect (https://ffxivcollect.com)

- **Link-out:** the "open on web" button opens `https://ffxivcollect.com/{mounts|minions|orchestrions|emotes|bardings|fashions|facewear|triad/cards}/{row id}` in the user's browser. Page ids match the game's sheet row ids (verified 2026-10-16 for mounts 1 and 18; minion and orchestrion ids matched the sheets one to one in the API). The plugin itself makes no network calls.
- **Bundled dataset:** `src/NekoDex/Data/unlocks.json` is generated by `tools/DataGen` from the public JSON API (`/api/mounts`, `/api/minions`, `/api/orchestrions`, `/api/emotes`, `/api/bardings`, `/api/fashions`, `/api/facewear`, `/api/triad/cards`), keeping only each entry's `sources` (`type`, `text`) and `patch`. The file is embedded in the plugin so unlock text works offline. Regenerate with `dotnet run --project tools/DataGen` from the repo root; the file records the generation date (`dataVersion`), the game version it was validated against and the highest mount id it knows, so newer mounts fall back to the web link.
- **Terms:** the about page describes the API as public for developers. No written license or rate limit was found on the site. The generator identifies itself with a `NekoDex-DataGen` user agent and makes one request per module per run (eight in total).
- **Action before public release:** ask the maintainer (Discord link on the site) whether redistributing the source text inside the plugin is acceptable, and record the answer here. Until then the dataset ships only to the private friends build.
- **Attribution:** every answer from the dataset shows "FFXIV Collect, data yyyy-mm-dd" in the UI; this file and the README credit the site.

## Garland Tools (https://www.garlandtools.org)

- **Link-out:** Garland has no pages for mounts, minions or other collectables as such; everything is an item. Links therefore go to `https://www.garlandtools.org/db/#item/{item id}` using the item that grants the collectable (the whistle, roll, card...). The item id comes from the game's Item sheet (ItemAction) at generation time, or from FFXIV Collect's `item_id`. Entries without an item id fall back to the FFXIV Collect page. (Before 2026-10-16 the plugin linked to `#mount/{id}` style pages that do not exist.)
- **Dataset fallback:** for entries FFXIV Collect lists without any source, DataGen reads Garland's item document (`/db/doc/item/en/3/{item id}.json`) and converts its `quests`, `achievements`, `instances`, `tradeShops`, `vendors`, `fates`, `ventures`, `craft` and `drops` fields into source lines, resolving names through the document's `partials`. One request per such entry with a 150 ms pause; typically a few dozen per run. Those entries carry `source: "Garland Tools"` and the UI attributes them to Garland.
- **Terms:** the site states no licence; it is written by Clorifex Ezalor and has a Discord. Same action as for FFXIV Collect before a public release: ask, and record the answer here.
- **Attribution:** "Garland Tools, data yyyy-mm-dd" shown next to every answer that came from it.
